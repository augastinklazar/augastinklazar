## 🔬 Some fun works...

- **High-Voltage Maritime Power & Blackout Simulator**  
  *Full-stack simulation modeling 4-generator load sharing, 6.6kV bus-tie synchronization, reverse power protection, and emergency sequence logic for training without high-voltage arc flash risks.*
- **Autonomous Dual-Axis Robotic Gimbal Tracker**  
  *Custom pan-tilt gimbal running on STM32 ARM Cortex-M4 with FreeRTOS. Features 1 kHz sensor fusion loop, Kalman filtering, and Field Oriented Control (FOC) for jitter-free orientation stability.*
- **Sub-GHz Industrial Marine Sensor Mesh**  
  *Long-range, low-power ESP32 + LoRa telemetry network monitoring bearing vibration, temperatures, and bilge fluid levels across harsh industrial machinery spaces.*
- **Interactive 3D LNG Engine Room Digital Twin**  
  *WebGL spatial explorer built with Three.js allowing real-time navigation through vessel power distribution systems, cryogenic compressors, and safety interlocks.*
- **Automated Creator Media Pipeline**  
  *CLI automation workflow built with Node.js and Python for audio denoising, dynamic schematic rendering, and rapid assembly of educational engineering media.*
